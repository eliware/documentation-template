## Scope and boundaries

Keep requirements in their authoritative specifications.

## Layout

Use README.md and specs/README.md to find maintained files.

## Development

Give each source and test module one cohesive purpose.

## Validation

Use Node.js 26 or later and native ESM for maintained JavaScript modules.
Run npm test for aggregate validation.
Run npm run lint for lint checks.
Run npm run audit for dependency checks.
Run npm run format to format files.
Run npm run format:check to check formatting.

## Security

Keep credentials, secret values, private data, and runtime state out of Git.

## Changes

Keep each document in the repository that owns its content.
When you add a document, update its nearest index.

## Documentation

Keep docs/README.md as the template guide. Replace it with end-user documentation for the derived repository.

## Private distribution

Keep this repository private. Share documents only with approved readers. Do not publish package content.
